# 사회복지 현장 생성형 AI 바로가기

사회복지 현장에서 바로 쓸 수 있는 생성형 AI 사이트 49개를 업무별 11개 폴더로 정리하고, 맨 아래에 복지인사이트 AI Tool 3개를 더한 웹앱입니다.
앱 이름 버튼을 누르면 실제 사이트가 새 창으로 열립니다.

## 사용법
- `index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 사용할 수 있습니다.
- 앱 이름이나 업무(예: 회의록, 카드뉴스, 번역)로 검색할 수 있습니다.
- "많이 쓰는 앱" 버튼으로 주요 서비스만 모아 볼 수 있습니다.
- 앱 아이콘 왼쪽 위 ☆를 누르면 즐겨찾기에 추가됩니다. "★ 즐겨찾기" 버튼이나 맨 위 "내 즐겨찾기" 폴더에서 모아 볼 수 있습니다.

## 즐겨찾기 저장 (DB 연결)
설정하지 않으면 즐겨찾기는 **사용하는 브라우저에만** 저장됩니다.
Supabase(무료)를 연결하면 이메일 로그인 후 **본인 계정에** 저장되어 다른 PC·휴대폰에서도 같은 즐겨찾기를 볼 수 있습니다.

1. https://supabase.com 에서 새 프로젝트를 만듭니다.
2. **SQL Editor**에 `supabase.sql` 내용을 붙여 넣고 Run 합니다. (각자 본인 즐겨찾기만 보이도록 보안 규칙까지 만들어집니다)
3. **Authentication → URL Configuration**의 Site URL과 Redirect URLs에 웹앱 주소를 넣습니다.
   예: `https://mediahelper2020-lab.github.io/ai_service/`
4. **Project Settings → API**에서 Project URL과 `anon` `public` 키를 복사해 `index.html` 위쪽의 아래 두 줄에 넣습니다.
   ```js
   const SUPABASE_URL = "https://xxxx.supabase.co";
   const SUPABASE_ANON_KEY = "eyJ...";
   ```
   anon 키는 웹페이지에 공개되어도 되는 키입니다. `service_role` 키는 절대 넣지 마세요.

Supabase 기본 메일 발송은 시간당 보낼 수 있는 수가 적습니다. 교육 현장에서 여러 명이 한꺼번에 로그인하려면 Authentication → SMTP Settings에서 메일 발송 서비스를 연결하세요.
