# 사회복지 현장 생성형 AI 바로가기

사회복지 현장에서 바로 쓸 수 있는 생성형 AI 사이트 49개를 업무별 11개 폴더로 정리하고, 맨 아래에 복지인사이트 AI Tool 3개를 더한 웹앱입니다.
앱 이름 버튼을 누르면 실제 사이트가 새 창으로 열립니다.

## 카테고리
AI 비서(6) · AI 브라우저·에이전트(4) · 자료조사·요약(6) · 회의록·음성기록(3) · 홍보물·이미지(7) · 발표자료·도식(3) · 영상·자막(6) · 음성·음악(3) · 번역·다문화(3) · 업무도구 만들기(3) · API 키 발급(5) · 복지인사이트 AI Tool(3)

## 사용법
- `index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 사용할 수 있습니다.
- 앱 이름이나 업무(예: 회의록, 카드뉴스, 번역)로 검색할 수 있습니다.
- "많이 쓰는 앱" 버튼으로 주요 서비스만 모아 볼 수 있습니다.
- 앱 아이콘 왼쪽 위 ☆를 누르면 즐겨찾기에 추가됩니다. "★ 즐겨찾기" 버튼이나 맨 위 "내 즐겨찾기" 폴더에서 모아 볼 수 있습니다.

## 즐겨찾기 저장
즐겨찾기는 브라우저에 들어 있는 저장소(IndexedDB)에 저장됩니다. 외부 서버나 로그인 없이 동작하고, 저장한 내용은 그 PC·브라우저 밖으로 나가지 않습니다.
- 같은 PC, 같은 브라우저에서는 창을 닫았다 열어도 그대로 남아 있습니다.
- 다른 PC나 다른 브라우저(크롬↔엣지)에서는 따로 저장됩니다.
- 시크릿 창에서는 창을 닫으면 사라지고, 브라우저의 "인터넷 사용 기록 삭제"로 사이트 데이터를 지우면 함께 지워집니다.
